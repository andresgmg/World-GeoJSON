geoworld examples

Three pages, one per adapter. Each reads the index of a pinned World GeoJSON data release through the geoworld client, lets you pick a territory and a level, draws it, fits the map from the index bbox and highlights features by their stable id.

  • Leaflet — geoworld-leaflet, Leaflet from a script tag (window.L)
  • MapLibre GL JS — geoworld-maplibre, feature state by id
  • React — geoworld-react hooks, no build step

Running them

From the repository root: just examples, or npm run build && python -m http.server 8000, then open http://localhost:8000/examples/. The pages import the packages from ../packages/js/*/dist/esm/ through an import map; Leaflet, MapLibre and React come from public CDNs.

Outside the repository, point the import map at the published packages instead, for example https://esm.sh/geoworld and https://esm.sh/geoworld-maplibre.
